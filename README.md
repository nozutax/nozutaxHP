# 野津税理士事務所 HP デザイン案

作成日：2026-07-24

現行サイト（https://nozutax.wixsite.com/nozutax）の内容を、HP作成会社の営業サンプル
（https://codejuice-preview.com/10232-野津税理士事務所/）のデザイン言語で組み直したデザイン案です。

## 見方

`index.html` をダブルクリックしてブラウザで開いてください。サーバーもインストールも不要です。

```
20260724事務所HP/
├─ index.html            … 1ページ完結の本体
├─ assets/css/style.css  … デザイントークン＋全スタイル
├─ assets/js/main.js     … スクロール演出・メニュー開閉・フォーム送信
├─ gas/                  … お問い合わせ用 Google Apps Script
│  ├─ Code.gs            … 通知メール＋確認メール
│  └─ デプロイ手順.md    … 初回セットアップ手順
├─ robots.txt            … クローラ向け（Sitemap URL は本番ドメイン後）
├─ sitemap.xml.example   … 本番ドメイン確定後に sitemap.xml 化
├─ llms.txt              … AI向けサイト要約（実験的）
├─ picture/              … 画像（ご提供いただいたもの）
│  ├─ cropped-aicon.jpg  … 事務所アイコン
│  ├─ kazuhiko.jpg       … 野津和彦さん
│  └─ kyota.jpg          … 野津亨太さん
└─ README.md             … このファイル
```

## 画像の使いどころ

| 画像 | 使用箇所 | 表示サイズ |
|---|---|---|
| `cropped-aicon.jpg` | ヘッダーのロゴ横／フッター／ブラウザタブのファビコン | 30px／39px |
| `kazuhiko.jpg` | 05 税理士紹介 | 92〜118px幅 |
| `kyota.jpg` | 05 税理士紹介 | 92〜118px幅 |

- **アイコンは白地の角丸チップに載せています。** 元画像が青×オレンジで背景が白のため、
  深緑の地にそのまま置くと白い四角が浮いて見えます。チップにすることで「意図した白」に見せています。
- **顔写真は表示サイズを118px以下に抑えています。** 元画像が小さく（和彦さん130×174px、
  亨太さん213×300px）、これ以上大きく表示するとぼやけるためです。実際の表示倍率は
  和彦さん0.71倍・亨太さん0.43倍で、どちらも拡大していません。
  **大きく載せたい場合は、より解像度の高い写真をご用意ください**（目安：短辺600px以上）。
  特に和彦さんの写真は元が小さいため、差し替えると印象が良くなります。

## Wix への反映について

この案を採用する場合、Wix への持ち込み方には次の3つがあります。作業量と再現度のトレードオフです。

| 方法 | 再現度 | 手間 | 備考 |
|---|---|---|---|
| **1. Wix エディタで手組み** | 中 | 大 | 既存のWixサイトに、このデザインを見ながらセクションを作り直す。マーキーやスクロール演出は完全には再現できない。追加費用ゼロ。 |
| **2. Wix Studio へ移行** | 高 | 中 | Wix Studio はCSSに近い制御ができるため再現度が上がる。ただしWix（無印）からの作り直しになる。 |
| **3. 制作会社に発注** | 高 | 小 | 営業を受けたサンプルの会社に、この案を要件として渡す。この案があると「何を作ってほしいか」が明確に伝わり、見積り比較もしやすくなる。 |

### 移植時に必ず差し替えが必要な箇所

- **お問い合わせフォーム**：Google Apps Script で `nozu.tax@gmail.com` へ送信＋送信者へ確認メール。
  初回は `gas/デプロイ手順.md` の設定が必要です（`assets/js/main.js` の `CONTACT_ENDPOINT` に URL を貼る）。
- **お客様の声**：開業・毎月訪問・医療法人化の実声に差し替え済み（匿名）。掲載許諾の最終確認はご判断ください。
- **Googleフォント**：Zen Kaku Gothic New と Archivo を使用しています。Wix にも同名フォントがあるか、
  なければ近いものへの置き換えが必要です。
- **画像**：`picture/` の3点をWix側にアップロードし直す必要があります。
- **SEO（ドメイン確定後）**：`canonical` / `og:url` / `og:image`（絶対URL）と `sitemap.xml` の本番化。Search Console・Googleビジネスプロフィールは公開後に登録。

## 動作確認

### ブラウザで実測して確認したこと

- 表示幅 **320 / 375 / 768 / 1024 / 1440px** で横スクロールなし、文字のはみ出しゼロ
- Hero見出しが320pxでも意図した2行に収まる（下限を切ると「の」が1文字だけ次行に落ちるため、
  `--size-display` の下限は viewport 追従にしてある）
- CONTACT見出しが1440pxで2行に収まる（2カラム時の左半分＝約516pxに対して調整済み）
- 1024px未満でハンバーガーに切り替わり、開く／閉じる／背後のスクロール固定／ロゴが前面に残る
- ヘッダーの全アンカー（9セクション）が、ヘッダー分の72pxオフセットで正確に着地
- ページ最下部まで一気にジャンプしても、フェードイン対象30要素すべてが表示される
- 画像4点すべてが読み込まれ、顔写真はどちらも元画像より小さく表示（拡大による劣化なし）
- Information の3リンクが正しいURL・別タブ・`rel="noopener"` で出力される（4件ともHTTP 200）
- FAQ のアコーディオンがクリックで開閉する（＋／−の切替も含む）
- フォームは未入力送信で「必須項目にご記入ください。」を表示。GAS デプロイ後は実送信される（手順は `gas/デプロイ手順.md`）
- JavaScript 無効時も全コンテンツが表示される（`html.js` が付いたときだけ隠す作り）
- コンソールエラーなし

### 仕様上こうなるが、この環境では実機確認できていないこと

- **FAQ のキーボード操作**：`<details>/<summary>` という標準の要素を使っているため、
  Tab＋Enter/Space で開閉するのがブラウザの仕様です。ただし自動操作環境では素の `<details>` でも
  Enter が効かなかったため、実機での確認は未実施です。お手元のブラウザでご確認ください。
- **OSの「視差効果を減らす」設定**：`prefers-reduced-motion` の指定は入れていますが、
  この環境ではOS設定を切り替えられないため未確認です。
- **Googleフォント不達時**：`font-family` にヒラギノ・游ゴシック・メイリオを併記しているため
  崩れない想定ですが、実際にフォントを遮断しての確認は未実施です。

### 確認用のローカルサーバー

`file://` で直接開くとブラウザによってはCSSが強くキャッシュされます。修正しながら確認するときは
以下でローカルサーバーを立てると確実です（`.claude/launch.json` に定義済み）。

```bash
python -m http.server 8765
```

起動後 http://localhost:8765 を開いてください。
