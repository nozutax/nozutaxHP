# お問い合わせフォーム（GAS）デプロイ手順

この手順を一度行うと、HPの「送信する」からメールが届くようになります。

所要時間の目安：10〜15分（初回の権限承認含む）

---

## 事前準備

- **必ず `nozu.tax@gmail.com` でログインしたブラウザ**で作業してください  
  （このアカウントからメールが送られます）

---

## 手順

### 1. Apps Script を開く

1. https://script.google.com/ を開く
2. 「新しいプロジェクト」をクリック
3. 左上の「無題のプロジェクト」を **`野津税理士事務所HPお問い合わせ`** に変更して保存

### 2. コードを貼る

1. エディタに最初からあるコードをすべて削除
2. このフォルダの `Code.gs` の内容をすべてコピーして貼り付け
3. フロッピーアイコン（保存）をクリック

### 3. ウェブアプリとして公開する

1. 右上の **「デプロイ」→「新しいデプロイ」**
2. 左の歯車アイコン → 種類で **「ウェブアプリ」** を選ぶ
3. 次のように設定する

| 項目 | 設定値 |
|------|--------|
| 説明 | HPお問い合わせ v1 など（任意） |
| 次のユーザーとして実行 | **自分** |
| アクセスできるユーザー | **全員** |

4. 「デプロイ」をクリック
5. 初回は権限の確認が出ます  
   - 「アクセスを承認」→ Googleアカウント選択（`nozu.tax@gmail.com`）  
   - 「このアプリは確認されていません」→ **詳細** → **（プロジェクト名）に移動（安全ではないページ）** → **許可**
6. 表示された **ウェブアプリの URL** をコピーする  
   （`https://script.google.com/macros/s/……/exec` の形）

### 4. HP側に URL を書き込む

1. `assets/js/main.js` を開く
2. 先頭付近の次の行を探す

```js
var CONTACT_ENDPOINT = '';
```

3. 空文字の中に、コピーした URL を貼る

```js
var CONTACT_ENDPOINT = 'https://script.google.com/macros/s/×××/exec';
```

4. ファイルを保存する

### 5. 動作確認

1. `index.html` をブラウザで開く（可能ならローカルサーバー）
2. お問い合わせ欄に **自分の別メール** などで入力して送信
3. 確認すること
   - `nozu.tax@gmail.com` に通知メールが届く
   - 入力したアドレスに「受け付けました」メールが届く
   - 画面に「送信しました…」と出る

---

## コードを直したあと

Apps Script のコードを変更したら、**保存だけでは公開版に反映されません。**

1. 「デプロイ」→「デプロイを管理」
2. 鉛筆アイコン（編集）
3. 「バージョン」で **新バージョン** を選ぶ
4. 「デプロイ」

URLは同じままで大丈夫です（`main.js` の書き換え不要）。

---

## トラブル時

| 症状 | 確認すること |
|------|----------------|
| 「送信設定が未完了です」 | `CONTACT_ENDPOINT` が空のまま |
| 送信失敗と出る | デプロイの「アクセスできるユーザー」が「全員」か／新しいバージョンを出しているか |
| メールが来ない | Apps Script を開いたアカウントが `nozu.tax@gmail.com` か／迷惑メールフォルダ |
| 連続で送れない | 同一メールは60秒に1回までの制限（正常動作） |

---

## セキュリティの要点（実装済み）

- ハニーポット欄（見えない入力欄）が埋まっていたらメールを送らない
- 同じメールアドレスからの送信は60秒に1回まで
- 文字数上限あり
- サイト側にパスワードやAPIキーは置かない
